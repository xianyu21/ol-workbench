# 05: 服务端 CORS 收紧

**What to build:** 本地服务不再对任意来源返回 `Access-Control-Allow-Origin: *`：默认不发该头，仅对工作台 UI 资源路径按需放行。效果：用户浏览器里打开的任意网页无法通过 fetch 探测 127.0.0.1 上的页面清单与本地目录信息。若实测发现某个 AxHub 导出依赖跨域读取，按"精确放行来源"处理而非整体放行。

**Blocked by:** 02 (本地服务请求层测试基线).

**Status:** ready-for-agent

- [ ] 测试断言：跨源请求响应中不再携带 `ACAO:*`（工作台资源路径按策略放行）
- [ ] 桌面端与 CLI 浏览器模式下工作台 UI 及原型页加载实测无回归
- [ ] 中文路径、iframe 嵌套、媒体资源播放不受影响
